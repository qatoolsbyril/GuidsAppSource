# Каталог кастомизации

Локальное приложение на Python и PySide6 для поиска и сбора GUID кастомизации нескольких игр.

Запуск: `python main.py` (требуется PySide6).

В верхней панели выбирается проект. Кнопка «Новый проект» открывает встроенную форму:
укажите название, категории и типы кастомизации, по одному на строку. Их можно дополнить
непосредственно при добавлении элемента. В «Настройки проекта → Проект» меняется название
проекта. Во вкладке «Структура каталога» доступны категории, их подкатегории и общие типы.

Выберите название в списке, действие и новое название или цель, затем нажмите
«Проверить изменение». Перед применением показываются описание и количество затронутых
элементов. Переименование обновляет все связанные записи и ветки дерева; переименование
типа также меняет ключ в выводе GUID. Объединение сохраняет элементы и их GUID.
Подкатегорию можно перенести в другую категорию или убрать, оставив её элементы в категории.
Пустые названия можно добавлять и удалять; заполненную ветку сначала нужно объединить
или перенести. Пустые подкатегории доступны как подсказки при добавлении элементов.

Перед каждым изменением структуры создаётся резервная копия в `.catalog-backups/<id>/`.
Кнопка «Отменить последнее изменение структуры…» восстанавливает предыдущее состояние.
Если после изменения структуры каталог или настройки уже менялись, автоматическая отмена
не выполняется, чтобы сохранить новые данные. Исходные пути иконок элементов остаются
рабочими; иконки подкатегорий копируются при переименовании и переносе. При объединении
сохраняется существующая иконка целевой подкатегории.

Слева находится каталог и поиск по имени или GUID. Двойной щелчок добавляет GUID
в список справа. Формы добавления, редактирования, создания и настройки проекта
плавно выезжают справа и занимают половину рабочей области, не изменяя размер окна.
Выбор изображений открывается внутри этой панели.
«Назад к GUID» закрывает форму без сохранения введённых изменений. После добавления
форма остаётся открытой для следующего элемента, после редактирования возвращается список GUID.
Пока форма открыта, переключение проекта заблокировано.
Клавиша Esc выполняет возврат из открытой формы. При выборе изображения первое
нажатие Esc возвращает к форме, следующее — к списку GUID.
Сохранение элементов выполняется в фоне с индикатором «Сохранение…».
Повторное сохранение и закрытие приложения до окончания записи заблокированы.
При ошибке введённые значения сохраняются в форме. После записи обновляется только
изменённый элемент каталога, без повторной загрузки всех иконок.
В форме редактирования доступна кнопка «Удалить элемент…». Удаление требует
подтверждения в отдельном диалоге с названием и GUID. Удалённый элемент также
исчезает из списка выбранных GUID. Файлы изображений сохраняются на диске.
Иконки стрел отображаются в области до 112×56, остальные — до 56×56,
с сохранением пропорций изображения.

Существующие `data/` и `assets/icons/` используются проектом «Основной проект» без переноса.
Новые базы хранятся в `projects/<id>/`, настройки и последний выбранный проект — в
`projects.json` рядом с приложением. Эта папка должна быть доступна для записи.
Для переноса всех локальных данных скопируйте `projects.json`, `projects/`, `data/`
и `assets/icons/`; для переноса истории изменений также скопируйте `.catalog-backups/`.
Общей базы и синхронизации между сотрудниками нет.

Проверки: `python -m unittest discover -s tests -v`.
